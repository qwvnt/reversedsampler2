# Reverse Sampler · тестовая сборка 0.22.0

## Тёплый старт нот и новые пресеты — версия 0.22.0

- **Аккорды в режиме Stretch больше не трещат.** Каждое начало стретч-ноты раньше считало спектр на месте (≈2 мс на стереослой): аккорд из 5 клавиш на двух слоях — 20 мс в одном блоке, никакой буфер этого не выдерживал, отсюда искажения на атаке. Теперь фоновый поток заранее прогревает стретчер для 24 нот вокруг последней сыгранной (на каждый слой), и старт ноты копирует готовое состояние (десятки микросекунд). Звук бит в бит тот же, что при расчёте на месте (есть тест); если ноты в кэше нет (первые ~0.3 с после смены настроек, сэмпла, темпа или прыжка больше октавы), она стартует по-старому. Память: около 1 МБ на запись при стерео, только в режиме Stretch. Аккорд из 6 нот в тесте: первый блок 10.1 → 4.7 мс при буфере 512.
- **Пресеты.** Убраны Dub, Metallic Comb, Pumping Drone, Breathing Tube; экстремальные настройки смягчены (Frozen Shimmer → Glass Shimmer, Endless → Soft Shimmer с коротким хвостом, Transient Eraser → Transient Softener и др.). Добавлено 60 новых — всего 109, по 15–20 на эффект, больше всего в Cinematic (27) и Ambient (33).
- Если при аккордах по-прежнему слышен перегруз на атаке и индикатор DAW показывает клиппинг: это сумма громкостей голосов (8 голосов полного уровня дают +18 дБ), а не нагрузка — уменьшите Volume или Level слоёв.

## Пресеты FX и разгрузка процессора — версия 0.21.0

- **Пресеты эффектов.** Кнопка **PRESETS** рядом с Type в каждом слоте. Для загруженного эффекта — его пресеты по жанрам (Ambient, Experimental, Cinematic, Electronic, Lo-Fi, Dub, Rock), для пустого слота — все эффекты. 53 заводских пресета, не меньше 5 на каждый эффект, большинство — ambient и experimental. Пресет ставит тип, сбрасывает остальные настройки слота к заводским и задаёт свои; маршрут A/B не трогает. Один Undo возвращает всё. Список — `Source/FxPresets.h`.
- **Треск при быстрой игре с 5 эффектами.** Замер сцены (`RS_SCENE_BENCH_ONLY=1`): всплеск на каждом начале ноты в режиме Stretch — это предварительный расчёт спектра (около 2 мс на стереослой), к нему добавлялась нагрузка рэка. Что изменилось без изменения звука:
  - Stretch: вход для пререолла читается один раз в буфер (одно ядро sinc на оба канала), а не sinc-ядро на каждое случайное обращение стретчера — начало ноты примерно на 20 % дешевле. Остальное — FFT, их ускорить без потери качества нельзя; при буфере 128 и большом количестве нот по-прежнему помогает буфер 256–512 или режим Resample.
  - Reverb: параметры пересчитываются только когда ручка двигалась, а установившийся ревербератор не считает скольжение на каждый сэмпл — примерно на четверть дешевле (это был самый тяжёлый эффект рэка).
  - Delay: коэффициент тона Tape (pow + exp) считается только пока движется Bias, косинус кроссфейда Replica — только пока идёт кроссфейд, сатуратор переиспользует первообразную прошлого сэмпла.
  - Compressor Vintage и Chorus Classic: ламповый каскад переиспользует первообразную прошлого сэмпла, tanh смещения — раз в тик.
  - Все изменения бит в бит: автотесты (362) проходят, включая точное сравнение рендеров.
- **Защита от NaN.** Reverb и Drive игнорируют нечисловые значения настроек вместо того, чтобы навсегда «отравить» фильтры (Chorus и Compressor так умели).
- **Бенчмарк сцены** получил тяжёлый вариант: Tape drive, Classic chorus, Shimmer, Tape delay, Vintage compressor на обоих слоях.
- **Исправления 0.21.1.** Выбор пресета ронял сборку на Windows: таблица пресетов хранила значения в `std::initializer_list`, у которого MSVC в constexpr-массиве не продлевает жизнь данных — теперь это обычный массив. В Mod Matrix неиспользуемые строки (Aux, Amount, Curve, ±) приглушены с самого начала, а не только после сброса. Полифония — 8 голосов (было 16): меньше одновременных стретчеров при быстрой игре.

## Mod Matrix, спектр EQ, сброс A/B — версия 0.20.0

- **Mod Matrix** (кнопка MOD MATRIX справа вверху). 16 строк: Source → Destination, Aux (второй источник, масштабирует строку, например Mod Wheel вводит LFO), Amount (±100 % диапазона параметра), Curve (изгиб источника), ± (биполярно вокруг положения ручки), живой индикатор выхода, × очищает строку.
- **Источники:** 4 макроса (на главной странице, имя меняется двойным щелчком в Mod Matrix), 2 LFO (Sine, Triangle, Saw Up/Down, Square, S&H, Random; Rate 0.02–30 Гц или Sync к темпу от 8 тактов до 1/32 с точками и триолями; Free / Retrig / One Shot; Phase; Smooth), огибающая ADSR (запускается нотой, педаль учитывается), Build (прогресс ноты от начала до PEAK — для реверс-свеллов), Velocity, Note, Mod Wheel, Aftertouch, Pitch Bend, Random (новое значение на каждую ноту).
- **Назначения:** Volume; Level / Pan / Width / Low Cut / High Cut каждого слоя; ручки, Mix и дополнительные настройки каждого слота FX (название берётся из текущего эффекта); Rate обоих LFO.
- **Правый щелчок по любой ручке** — меню «Add modulation from…», удаление её модуляций, открытие Mod Matrix. Модулируемые ручки показывают фиолетовое кольцо: диапазон модуляции и текущее положение.
- Модуляция не меняет параметры хоста: автоматизация и Undo работают как раньше. Без активных строк звук бит в бит прежний; с активными строками слои и FX обновляются каждые 32 сэмпла. Перестановка слотов переносит их модуляции, смена эффекта в слоте очищает строки, которые вели к нему (одно Undo возвращает всё).
- **Живой спектр в EQ:** серая линия — вход, заливка — выход, с наклоном 4.5 дБ/октаву; кривая EQ показывает модуляцию. Захват звука идёт только пока окно открыто.
- **Empty сбрасывает и A/B:** выбор Empty возвращает маршрут слота к обоим слоям. Одно Undo возвращает эффект вместе с прежним A/B.
- **Сборка на Windows (MSVC):** меню модуляции по правому щелчку использовало локальные константы внутри лямбды без захвата (ошибка C3493 в `ModMatrixEditor.cpp`). Константы вынесены на уровень пространства имён, как раньше в компрессоре.
- **Destination в Mod Matrix — вложенное меню.** Вместо одного списка на 110 пунктов: None → Global → Layer 1 / Layer 2 → FX 1…5 → LFO. Показаны только слоты с загруженным эффектом и только те его параметры, которые у этого типа есть (у Delay нет Knob 3, у EQ нет Diffusion и т. д.). Строка, ведущая к уже выгруженному эффекту, остаётся видна, пока вы её не смените.
- **Оптимизация без изменения звука.** Когда модулируются только параметры слоёв или ничего, FX-рэк и мастер-громкость обрабатываются одним блоком, а не кусками по 32 сэмпла (раньше любая активная строка включала 32-сэмпловую нарезку для всего тракта). Матрица пересчитывает только те назначения, к которым ведут строки, и читает настройки LFO/огибающей раз в блок. В Delay убраны целочисленные деления в цикле сэмплов и пересчёт констант фильтров в каждом вызове; компрессор не считает `pow`/`tanh` на каждый сэмпл, пока понижение не меняется.

## Исправления и изменения — версия 0.19.0

- **Сборка на Windows (MSVC) снова проходит.** Компилятор Visual Studio не принимал лямбду в ламповом каскаде компрессора: внутри неё использовалась локальная константа, которую MSVC требует явно захватывать. Константа вынесена на уровень пространства имён.
- **Шум в хорусе убран полностью.** Ни в одной модели нет ни шипения, ни шума клока: тишина на входе даёт ровно тишину на выходе. Слот засыпает через 0.25 с тишины (было 1.5 с).
- **Empty сбрасывает слот.** Выбор Empty в меню Type возвращает все настройки слота к значениям по умолчанию (A/B не меняются). Эффект, выбранный потом, стартует с заводскими настройками. Одно Undo возвращает эффект со всеми его ручками.
- **Названия моделей без реальных приборов.** Модели хоруса: Classic, Spatial, Liquid, Digital, Poly, Sine, Ensemble. Номера моделей не менялись, проекты 0.18 открываются как раньше. Кнопки Digital: PITCH, MOD, MULTI; кнопка Liquid: DARK. Подсказки в окне FX тоже без названий приборов.
- **Нагрузка на процессор (замер, без изменений в звуке).** В режиме Stretch каждое начало слоя прогоняет предварительный расчёт спектра. Это около 1–1.5 мс на стереослой на тестовой машине, а обычный блок занимает 0.03 мс. При быстрой игре на буфере 128 сэмплов такой всплеск может не успеть за один блок. Ускорить этот расчёт без потери качества нельзя. Если звук прерывается: буфер 256–512 в DAW или режим Resample у слоя, которому не нужна независимая от высоты длина (Resample примерно в 10 раз дешевле и без всплесков). Бенчмарк сцены: `RS_SCENE_BENCH_ONLY=1 ReverseSamplerTests`.

## Compressor: Vintage / Modern — версия 0.18.0

Новый тип FX **Compressor**. Ручки: **Threshold** (−60…0 дБ), **Ratio** (1:1…20:1), **Makeup** (0…+24 дБ), **Mix** (параллельная компрессия), режимы **VINTAGE / MODERN**.

| Режим | Как устроено | Свои ручки |
|---|---|---|
| **Vintage** | тёплый медленный «клей» ламповых variable-mu и оптических компрессоров. RMS-детектор (4 мс, Opto — 10 мс) с ФВЧ 60 Гц в сайдчейне, поэтому бас не «качает». Широкое колено 18 дБ: у порога сжатие мягкое, выше — всё плотнее. Release зависит от программы: чем дольше шло сжатие, тем медленнее отпускание. Ламповый каскад со смещением даёт в основном 2-ю гармонику, и тем больше, чем сильнее сжатие (≈1.7 % при 13 дБ GR); трансформатор насыщает низ и чуть смягчает верх | **TIME 1–6**: 1 — 0.2 мс / 0.3 с, 2 — 0.2 мс / 0.8 с, 3 — 0.4 мс / 2 с, 4 — 0.4 мс / 5 с, 5 — 2 с → до 10 с, 6 — 0.3 с → 10 с → 25 с. **OPTO**: атака 10 мс, половина отпускания за 60 мс, остальное за 1–15 с в зависимости от того, как долго шло сжатие |
| **Modern** | максимально прозрачный feed-forward компрессор: пиковый детектор, сглаживание в логарифмической области, квадратичное колено. Без окраски, без задержки; ниже порога сигнал проходит бит в бит | **Knee** 0–24 дБ, **Attack** 0.05–250 мс, **Release** 5–2500 мс |

Визуализация в слоте:
- **Кривая передачи** (вход → выход с учётом Makeup и Mix): подсвечена зона колена, порог показан пунктиром, диагональ 1:1 — для сравнения. Белая точка — текущий уровень на входе и выходе.
- **Индикаторы I / GR / O:** вход, подавление усиления (сверху вниз) и выход.
- **История за 4 с:** уровень входа (серым), уровень выхода (цветом) и красная линия GR — видно, сколько срезано и как компрессор отпускает.

Оба слоя связаны по стерео (L и R сжимаются одинаково), у каждого слоя своя история. Переключение Vintage ↔ Modern — плавный переход 0.16. CPU: около 1 % ядра.

### Изменения хоруса и исправления в 0.18.0

- Одна модель хоруса удалена, ручки **Noise** и **Input** тоже. В проектах 0.17 номер модели сдвинулся: Digital, Poly, Sine и Ensemble откроются на одну позицию раньше в списке.
- **Меню Type иногда не переключало слот.** Таймер окна FX раз в 100 мс возвращал меню к значению параметра. Если он срабатывал между выбором пункта и обработкой выбора, меню откатывалось на Empty и выбор терялся. Теперь таймер не трогает меню, пока выбор не применён.
- У Splice в Amethyst отображалось «350 ms ms».

## Chorus — версия 0.17.0

Новый тип FX **Chorus**, семь моделей. У каждой модели свои ручки и своё поведение.

| Модель | Как устроено | Ручки и кнопки |
|---|---|---|
| **Classic** | тёплый аналоговый хорус: одна BBD-линия на 256 ячеек, задержка 1.3–4.3 мс; входной преамп, в режиме High добавляется транзисторный каскад (ADAA). Преамп остаётся в тракте и при Mix 0 | CHORUS / VIBRATO, Intensity (в Chorus меняет скорость 0.3–3 Гц и глубину вместе), Rate (3.1–11 Гц) + Depth в Vibrato, HIGH, CLASSIC (L сухой, R мокрый) / DUAL (две линии, LFO со сдвигом 90°) |
| **Spatial** | пространственный хорус: две BBD-линии на 512 ячеек, один LFO-треугольник в противофазе, ФВЧ 80 Гц, компандер; на каждый выход идёт в основном мокрый сигнал другого канала, высота почти не плавает | 1, 2, 3, 4, 1+4, 2+4, 3+4 (1: 10 ± 2 мс, 0.25 Гц; 2: 7.5 ± 2.5 мс; 3: 7.5 ± 1.5 мс, 0.5 Гц; +4 — больше мокрого; 4 = 3+4) |
| **Liquid** | густой «водянистый» хорус: BBD на 512 ячеек, двойное моно (стерео сэмплов сохраняется) | Rate 0.1–8 Гц, NORMAL / DEEP, DARK (задержки ×1.5, темнее) |
| **Digital** | чистые интерполированные линии без окраски | PITCH (настоящий питч-шифтер: −9 / +11 центов, 15 / 25 мс при Detune 50 %), MOD (модулированная задержка с движением панорамы и уровня), MULTI (2–8 голосов, у каждого своя задержка, скорость, фаза, панорама и фильтр); Delay, Feedback, Voices |
| **Poly** | хорус винтажного синтезатора: две BBD-линии на 128 ячеек, у правой LFO инвертирован | I (0.513 Гц), II (0.863 Гц), 1.66–5.35 мс; I+II — 9.75 Гц, 3.3–3.7 мс, моно |
| **Sine** | классический цифровой хорус с синусным LFO, правый канал сдвинут на 90° | Rate 0.05–10 Гц, Depth, Delay, Feedback |
| **Ensemble** | струнный ансамбль: BBD-линии на трёхфазном LFO (медленный хорус + быстрое вибрато) | 3 LINES (моно) / 6 LINES (сдвиг 60°, стерео), Chorus Rate / Depth, Vibrato Rate / Depth |

Общие ручки у всех моделей: **Mix** (равномощностный, 50 % = сухой и мокрый поровну; 100 % — только мокрый, для вибрато), **Width** (стереобаза мокрого сигнала), **Output** (−24…+12 дБ); у аналоговых моделей ещё **HQ**.

- **BBD-ядро.** Линия из N ячеек с переменным клоком (задержка = N / f клока), клок линейно зависит от LFO, поэтому развёртка задержки несимметрична. Входной фильтр перед выборкой, мягкое насыщение в ячейках, выходной аналоговый ФНЧ 4-го порядка. На низком клоке (Poly, Dark) слышен лёгкий алиасинг, как у аналоговых схем. Медленный дрейф скорости LFO ±0.5 %.
- **HQ** (по умолчанию включён): ступени на выходе BBD интегрируются точно, в момент тика клока, без привязки к сетке сэмплов. Это BLEP-подобная схема, лишнего алиасинга нет. Без HQ ступени попадают на сэмплы и звук получается грязнее.
- Шума нет (с 0.19).
- Смена модели, режима у Digital / Ensemble, Dark у Liquid — плавный переход по схеме 0.16 (около 60 мс). Остальные кнопки (Spatial, Poly, Classic) меняют скорость и глубину с глайдом 40 мс, без перезапуска.
- CPU: 2–4 % одного ядра на слот с двумя слоями при 48 кГц.
- Совместимость: старые проекты и пресеты открываются как раньше. В параметр Type добавлен пункт Chorus, поэтому шкала Type сдвинулась: уже записанная в DAW автоматизация Type может указывать на другой эффект.
### Исправления в 0.17.0

- Amethyst в режиме REVERSE при синхронизированной задержке больше ~1.7 с и длинном Splice давал провалы в тишину: буфер зёрен был короче самой дальней точки чтения. Буфер увеличен до 2 с + 3 × 0.35 с.
- Запрос сброса слота мог потеряться, если приходил одновременно с другим (перестановка слотов, загрузка проекта). Теперь бит запроса снимается атомарно.
- Проект, в котором нет каких-то параметров слоя (сохранён старой версией), при загрузке в открытый экземпляр сохранял текущие значения этих параметров, а не значения по умолчанию. Раньше это исправлялось только для FX, теперь для всех параметров.
- Повторное нажатие той же ноты: старый голос уже затухал, а при отпускании клавиши его релиз начинался заново и звучал дольше заданного. Теперь релиз не перезапускается.
- Нехватка памяти при загрузке очень большого файла оставляла слой в состоянии «Loading…» навсегда, а оффлайн-рендер каждый раз ждал 60 с. Теперь выводится ошибка.
- Два теста падали ещё на 0.16 из-за устаревших ожиданий: Splice по умолчанию 350 мс, а не 250; в Arrive тест проверял не тот слой. Код в обоих случаях был верным.


## Переключения в FX без щелчков — версия 0.16.0

- **Смена эффекта без щелчка и без провала громкости.** Всё, что перезапускает эффект в слоте (Type, стиль Delay, Replica Vintage/Modern, направление Amethyst, включение слоя A/B, сброс), идёт в три шага по 20 мс: старый эффект затихает, новый стартует с чистого состояния — сначала плавно открывается его вход (выход ещё сухой), потом он сам появляется на выходе. Всего около 60 мс; молчащий слот переключается сразу. В 0.15 каждое такое переключение щёлкало (вторая разность сигнала до 0.36 при 0.0003 на ровном звуке); теперь край переключения не отличается от ровного звука, а ровный EQ при смене типа держит уровень 1.00.
- **Старый эффект доигрывает со своими ручками.** Пока он затихает, его ручки заморожены. Окно FX ставит сначала Type, потом нейтральные ручки нового эффекта; Undo/Redo сначала возвращает Type, стиль, Replica и направление, потом ручки. Раньше, например, Tape или Amethyst взвизгивали, когда Time прыгал на полсекунды прямо во время затухания.
- **Time у Tape и Amethyst скользит, как мотор ленты:** скорость головки от 1/4 до 4× (±24 полутона), никогда назад, инерция 5 мс. Раньше при резком изменении Time головка проносилась по ленте со скоростью до ~15× (при увеличении Time — задом наперёд) и трещала. Небольшие изменения (до ~22 мс длиннее или до ~90 мс короче) звучат как прежний 30-мс глайд; большой сдвиг слышен как съезд высоты тона — это намеренно, как на ленте (40 → 520 мс занимает около 0.65 с).
- **Сброс слота затихает, а не обрывается** (перестановка слотов, загрузка пресета или проекта). Запросы сброса не теряются, даже если пришли одновременно.
- **Bypass в хосте:** первый блок обхода останавливает все ноты и очищает хвосты шин слоёв и FX; пока обход включён, инструмент молчит, а экранная клавиатура следит за MIDI. После снятия обхода ничего не доигрывает и не зависает. Новый старт воспроизведения (prepareToPlay) тоже глушит все голоса.
- Статичные сцены звучат бит в бит как в 0.15: изменилось только поведение в моменты переключений.

## Интеграция модулей — версия 0.15.0

- **Смена типа эффекта загружает нейтральные значения ручек.** P1/P2/P3/Mix общие для всех эффектов (ID автоматизации не меняются), поэтому раньше, например, Time бывшего Delay превращался в скрытый срез Low у нового EQ. Теперь выбор типа в окне FX ставит: Delay 520 ms / 35 % / mix 35 %, EQ ровно (0 dB), Drive +10.8 dB / тон 50 / выход 0 dB / mix 100 %, Reverb Size 50 / Decay 40 / Tone 50 / Mix 30 %. Это один шаг Undo. Автоматизация Type из хоста и загрузка пресета ручки не трогают.
- **Idle gate.** Сэмплер почти всё время молчит, а реверб/делей раньше считали тишину. Если вход и выход слоя в слоте ниже -120 dB дольше самой длинной внутренней задержки эффекта (Delay 6.5 s, Reverb 0.5 s, EQ 0.3 s, Drive 0.1 s), слой пропускается, а его история очищается. Любой звук будит его в том же блоке с чистого состояния, хвосты никогда не обрезаются: сначала они затухают ниже -120 dB.
- Порядок цепи не изменился: голоса и прослушивание слоя → шина слоя (Level/Pan/Width/Low/High Cut) → FX 1…5 (A/B для каждого слоя) → сумма → Gain.

## Reverb: Room / Plate / Ambience / Terrain / Bloom / Shimmer — версия 0.13.0

Стерео-реверб с шестью режимами. Ручки: **Size**, **Decay** (показывает RT60 в секундах для текущего режима), **Tone**, **Mix** (равномощностный dry/wet), **Pre-Delay** (0–250 мс), **Low Cut** (чистый HPF на входе реверба, 20–1000 Гц) и **Character** — своя функция в каждом режиме.

| Режим | Алгоритм | Decay | Character |
|---|---|---|---|
| Room | ранние отражения (tap-сетка комнаты) + FDN 16 линий | 0.2–4 с | Early — уровень ранних отражений |
| Plate | диффузоры + модулированная петля пластины (Dattorro-подобная), мгновенная плотность | 0.4–10 с | Modulation |
| Ambience | короткие плотные отражения без слышимого хвоста | 0.1–1.5 с | Width (с сохранением мощности) |
| Terrain | дискретные эхо от далёких поверхностей, темнеют с расстоянием и затухают по RT60, поверх мягкого FDN | 0.3–8 с | Scatter |
| Bloom | «нарастающее облако» из 16 тапов на канал + сглаживающий FDN<8> → FDN<16> | 1–30 с | Attack — время нарастания 50 мс…1.2 с |
| Shimmer | большой холл, в петле которого гранулярный сдвиг на +12 полутонов; октавы каскадом растут в хвосте | 1–30 с | Shimmer — количество октав |

Частотно-зависимое затухание (низ/середина/верх по отдельным RT60), модуляция линий против металлического звона, денормалы отключены (FTZ/DAZ), смена режимов и параметров без щелчков. Общий для двух слоёв только набор настроек — история у каждого слоя своя.

## Drive: Tube / Soft Clip / Tape / Triode — версия 0.12.0

Полнополосный дисторшн: одна и та же обработка на всех частотах. Каждый новый тип — физическая модель реального прибора, а не просто кривая.

| Тип | Прообраз | Как устроено |
|---|---|---|
| **Tube** | ламповый сатуратор | без изменений: смещённый tanh, 2-я гармоника, sag, мягкий верх ~13 кГц |
| **Soft Clip** | диодная овердрайв-педаль | точное уравнение Шокли для пары кремниевых диодов в обратной связи ОУ (решается заранее в таблицу); чистый сигнал проходит параллельно, как в оригинале; диоды разбалансированы на 20 % → лёгкая 2-я гармоника |
| **Tape** | студийный магнитофон | гистерезис намагничивания Jiles–Atherton (RK2), предыскажения 50 мкс (ВЧ насыщаются раньше), head bump +1,5 дБ на 60 Гц, щелевые потери на верхах |
| **Triode** | триодный каскад предусилителя | модель триода, нагрузочная прямая (B+ 300 В, Ra 100 кОм, Rk 1,5 кОм), сеточный ток и «blocking» (смещение уплывает при перегрузе), эффект Миллера |

Ручки: **Drive** 0…100 % = 0…+36 дБ, **Tone** (НЧ-фильтр 500 Гц…20 кГц), **Output** (50 = 0 дБ), **Mix**. Кнопки TUBE / SOFT CLIP / TAPE / TRIODE.

- 4x передискретизация + ADAA первого порядка для всех типов (для Tape — усреднение намагниченности по сэмплу, аналог ADAA для системы с памятью).
- Автокомпенсация громкости, Mix внутри передискретизации (без гребёнки), смена типа — кроссфейд 20 мс.
- Совместимость: ID параметров прежние. В старых проектах тип сохраняется по номеру: Tube остаётся Tube, бывшие Fold/Octave/Hybrid откроются как Soft Clip/Tape/Triode.


## EQ Vintage / Modern — версия 0.10.0

Ручки: **Air, Treble, Mid, Low** (±12 дБ, центр = 0 дБ) и **Low Cut / High Cut** (крайнее положение = Off). Low/Mid/Treble остались на прежних ID (p1–p3), поэтому старые проекты и автоматизация работают.
- **Vintage** — характер пассивных ламповых эквалайзеров: широкие пологие подъёмы и связанные с ними мягкие провалы (Low +6 дБ на 15 Гц с провалом около 300 Гц; Treble с провалом около 800 Гц; Air с провалом около 3.5 кГц). Кривые подогнаны к присланным эталонам (погрешность подгонки ≤ 0.13 дБ). Шкала ручек — 0…10, как на аналоговых приборах.
- **Modern** — чистый EQ: значение на ручке точно равно усилению.
- **Low Cut / High Cut** — чистые Butterworth 12 дБ/окт, одинаковые в обоих режимах.
- Переключение режима и любая автоматизация происходят без щелчков. EQ всегда 100 % wet: параллельное смешение EQ даёт гребенчатый фильтр, поэтому Mix для EQ скрыт.
- Фильтры спроектированы методом matched-z (Vicanek): в отличие от обычных biquad-фильтров, ВЧ-полки не «сжимаются» у Найквиста. Отклонение от аналогового прототипа до 20 кГц: ≤ 0.7 дБ на 44.1/48 кГц и ≤ 0.25 дБ на 96 кГц.
- Оптимизация: коэффициенты пересчитываются только во время движения ручки (раз в 32 сэмпла); секции с 0 дБ отключаются; в нейтральном положении EQ — побитовый bypass. Полный EQ на двух стереослоях занимает около 0.7 % одного ядра.

## FX rack и Delay — версия 0.9.0

Кнопка **FX RACK** открывает пять последовательных слотов. A / B направляют слот на слои 1 / 2 независимо; история эффекта у каждого слоя отдельная. Заголовок слота перетаскивается для обмена эффектов и настроек местами. Undo/Redo работает и для перестановки. Автоматизация DAW остаётся привязана к **номеру слота**, а не следует за перетаскиваемым эффектом.

**Delay** теперь имеет четыре характера (это самостоятельные приближения, не точные копии коммерческих устройств):
- **Reverse** — обратные зерна; все повторы сохраняют обратный характер. На границах зерен — короткое косинусное перекрытие без периодических провалов до нуля. **Diffusion** управляет плотностью четырёх коротких all-pass каскадов без параллельного подмешивания фазосдвинутого сигнала.
- **Tape** — ограниченная полоса, мягкая сатурация и лёгкие фиксированные wow/flutter; нестабильность не настраивается отдельно. **Bias** меняет оттенок от более тёмного к более яркому.
- **Replica** — отдельные Modern/Vintage voicing: Modern чище и ярче, Vintage темнее и мягко насыщается; **HI-CUT** затемняет повторы. Это моделирование характера, а не измеренная или гарантированно идентичная копия педали T-Rex Replica.

- **Amethyst** — кристаллическое гранулярное эхо с одним чистым сдвигом на октаву вверх и двумя перекрывающимися окнами для непрерывного звучания. **Reflections всегда 1**; прежний ID сохранён для совместимости. **Feedback** возвращает сдвинутые кристаллические зерна в тракт без повторного повышения высоты. **Splice / Grain** — длина входного фрагмента 150–700 мс; ручки Time, Feedback, Mix и Splice расположены в одной колонке, ниже — **REVERSE / FORWARD**. Перед сдвигом стоит антиалиасный фильтр, а новое зерно фазово выравнивается по соседнему. Дополнительная длина зерна создаёт характерный разлёт относительно Time, поэтому ритм не строго совпадает с выбранной долей.


Общие **Feedback** и **Mix**; feedback 0–100% на ручке соответствует коэффициенту обратной связи 0–65% для устойчивости. Time без Sync: 40–1000 мс, можно ввести значение в поле под ручкой. **SYNC** берёт BPM у DAW: 1/32–1/1, обычные доли, триоли (T) и пунктир (.). Если DAW не сообщает темп, используется последний полученный, изначально 120 BPM. В синхронизации фактическое время ограничено 2 секундами: длинные доли на медленном темпе будут короче написанного значения (появится предупреждение **Time (limited: 2 s)**). Параметры задержки 0.7 остаются в том же диапазоне и с теми же ID; новые параметры в старых проектах получают значения по умолчанию. Режим по умолчанию — Replica Modern, поэтому старый Delay 0.7 может звучать иначе: прежний Tone больше не применяется в Delay. EQ не изменён; насыщение Drive теперь использует ADAA, что уменьшает алиасинг и немного меняет ВЧ-характер.

Velocity не нормализуется автоматически. Tape и насыщение Vintage нелинейны и могут менять соотношение уровней в зависимости от динамики источника. При высокой обратной связи или нескольких одновременно звучащих нотах повторы складываются и могут стать громче, особенно у Amethyst; уменьшите Feedback или громкость слоя при перегрузке.

Смена типа эффекта, характера delay, Vintage/Modern, маршрута A/B или направления Amethyst, перестановка слотов и загрузка проекта сбрасывают соответствующий хвост. Time сглаживается в Tape/Amethyst, Replica переключает стационарные головки с переходом 30 мс, Reverse принимает новую длину на границе зерна с перекрытием. Feedback, Diffusion, Bias, Hi-Cut и параметры Drive сглажены. Резкая смена Splice или режима всё ещё может вызвать скачок. Звучание старых проектов намеренно меняется из-за новых DSP и фиксированного Reflections. Плагин сообщает DAW максимальный хвост 180 секунд; некоторые DAW могут добавить тишину к экспорту. Noise пока не реализован. Детали изменений, замеры, команды сборки и ограничения проверки: [AUDIO_QUALITY.md](AUDIO_QUALITY.md).


**EQ**: см. раздел 0.10.0. **Drive**: насыщение, Tone, Output, Mix.


В 0.6.0 (интерфейс по-прежнему тестовый):
- **Сэмплы загружаются в фоне.** Окно и DAW не подвисают даже на длинных MP3. Пока файл грузится, на слое написано «Loading: имя файла», а прежний сэмпл звучит, пока новый не будет готов. Новый файл на тот же слой заменяет незаконченную загрузку, **Clear** и **Undo** её отменяют.

- **Исправлено**: переключатели слоя **ON** и **R** могли после открытия проекта или пресета показывать другое значение, если DAW перед этим записала в них автоматизацию с промежуточным значением (нашёл pluginval). Теперь они всегда строго включены или выключены. Старые проекты открываются как раньше.

В 0.5.0 доведена до релизного состояния вкладка сэмплера (интерфейс по-прежнему тестовый):
- **Clear** в настройках слоя убирает сэмпл и возвращает **все** настройки слоя (Root, Start/End, Mode, Length, Peak offset, Pitch, Level, Pan, Width, фильтры, ON, R) и его огибающую к значениям по умолчанию.

Голос, который забирает новая нота (больше 8 нот), и ноты, которые останавливает смена сэмпла, теперь затухают за 5 мс вместо щелчка.

В 0.4.2: если сдвинуть слой на шкале раньше начала ноты, его начало теперь обрезается, а PEAK и второй слой остаются на месте. Раньше в этом случае всё остальное уезжало позже.

В 0.4.1 исправлен **After peak** при сдвинутых пиках. **PEAK** (флажок на шкале) теперь один момент для всех слоёв: Cut, Freeze, Loop и Release начинаются именно там, а не там, где кончился слой. **Freeze** замораживает звук ровно в точке PEAK (плавный переход 20 мс, без щелчка). **Loop** перезапускает все слои вместе на PEAK. **Dissolve** заменён на **Release**: после PEAK сэмпл просто играет дальше и затухает за время **Fade** по нарисованной кривой, без грейнов и щелчка.

Всё из 0.3 (Swell / Arrive, совпадение пиков, Cut / Freeze / Loop, огибающие, редактор SAMPLE) на месте. Интерфейс тестовый, минимальный.

- Под SAMPLE: **SWELL | ARRIVE**, **After peak**, **Attack, Release, Volume**.
- **Undo** и **Redo** слева и справа от заголовка (то же, что Cmd/Ctrl+Z и Cmd/Ctrl+Shift+Z).
- Drag & drop, размеры окна и заглушки (Library Editor, Macro Editor, макросы) как в 0.2.1.

## Работа с сэмплами (новое в 0.4)

На Mac **Cmd** и **Option**, на Windows и Linux **Ctrl** и **Alt**.

| Где | Действие | Что происходит |
|---|---|---|
| шкала (SAMPLE и редактор SAMPLE) | **Shift + перетаскивание** слоя | двигает этот слой (Peak offset). Второй слой и PEAK стоят на месте. Если слой уходит раньше начала ноты, его начало обрезается: на дорожке зубчатый край и подпись «start trimmed», от слоя остаётся минимум 50 мс. Прилипает к транзиентам, к началу/концу другого слоя, к PEAK и к началу ноты (так обрезку легко убрать); рядом видна линия прилипания и значение |
| | **Shift + Option/Alt + перетаскивание** | то же без прилипания |
| | **Shift + двойной щелчок** по слою | Peak offset = 0 |
| | **перетаскивание флажка PEAK** влево | общий пик раньше (**Peak Move**): все нарастания кончаются раньше, начала не сдвигаются. Прилипает к транзиентам (Option/Alt: без прилипания). Отрезанная часть видна тусклой, пунктир = естественный пик |
| | **двойной щелчок по флажку PEAK** | пик на место |
| | **Option/Alt + щелчок и удержание** слоя | слой звучит один, ровно как в общем звуке (его огибающая, Peak Move, финальная огибающая, панорама, After peak), пока держите кнопку |
| | **Cmd/Ctrl + колесо** | увеличение вокруг мыши (вплоть до отдельных сэмплов); колесо без Cmd прокручивает; **двойной щелчок по шкале времени** внизу показывает всё |
| огибающие | **Cmd/Ctrl + щелчок** по точке | уровень точки по умолчанию (100 %, у кривой Release исходная кривая); Cmd/Ctrl + протаскивание сбрасывает все точки на пути |
| настройки слоя | **щелчок и удержание на волне** | слой звучит один (как Option/Alt на шкале) |
| | **Clear** | убирает сэмпл и сбрасывает все настройки слоя и его огибающую (отменяется Cmd/Ctrl+Z) |
| везде | **Cmd/Ctrl+Z** | отменить последнее действие (до 8 шагов) |
| | **Cmd/Ctrl+Shift+Z**, **Ctrl+Y** | повторить отменённое |

Транзиенты (резкие подъёмы громкости) находятся при загрузке файла и показаны короткими метками на дорожках. Во время перетаскивания они ярче.

- **Peak** (Peak Move) в редакторе SAMPLE: та же величина, что у флажка PEAK, 0…−30 с.
- **Release** (After peak): после пика на шкале рисуется кривая затухания (по умолчанию плавная, близко к (1 − x)²). Её можно рисовать как остальные огибающие. **Flat** сбрасывает и финальную огибающую, и эту кривую.
- **Peak offset** теперь меняется плавно, без шага.

## Как играет нота

- **Swell** (по умолчанию): нарастание начинается с нажатием клавиши, пик наступает позже, через длину самого длинного слоя.
- **Arrive**: пик приходит точно на ноту. Плагин сообщает DAW задержку (latency), равную самому длинному нарастанию, и DAW подаёт ноты заранее. Отпускание клавиши тоже сдвигается на эту задержку, поэтому короткая нота всё равно доходит до пика. Если на далёкой ноте слой (в Resample) длиннее задержки, его начало обрезается, а пик всё равно приходит вовремя.
- **Пики слоёв совпадают**: более короткий слой ждёт. **Peak offset** в настройках слоя сдвигает его нарастание (+ позже, − раньше), второй слой не трогается. Сдвиг раньше не двигает PEAK: если слой начался бы до нажатия клавиши, его начало обрезается (слой звучит с середины). Сдвиг позже самого длинного слоя, как и раньше, переносит PEAK так, чтобы нарастание всё равно начиналось с клавиши.
- **PEAK** один на всю ноту (флажок на шкале; Peak Move двигает его раньше). Все слои играют до него, и After peak начинается на нём для всех слоёв сразу. Слой, который кончился раньше PEAK (отрицательный offset), после своего конца молчит и в Freeze не держится. Часть слоя после PEAK (положительный offset или Peak Move) в Cut отрезается, в Release звучит и затухает. Треугольник над дорожкой отмечает конец нарастания слоя, если его offset не 0.
- **After peak**: **Cut** (звук кончается на PEAK, короткий выход 2 мс), **Release** (сэмпл играет дальше и затухает за время **Fade**, 0,1–20 с, по нарисованной кривой; если кривая кончается не в нуле, звук идёт до конца материала на этом уровне), **Freeze** (звук в точке PEAK держится, пока нажата клавиша: облако коротких грейнов из последних 300 мс перед PEAK, вход через плавный переход 20 мс), **Loop** (всё нарастание повторяется от начала, все слои вместе, пока нажата клавиша; длина цикла = от начала до PEAK).
- **Release** и его **Curve**: 0 = прямая, + быстро падает и долго тянет хвост, − дольше держится и обрывается в конце.
- **Огибающие громкости** (рисуются мышью): у каждого слоя своя (от начала нарастания до его пика) и **финальная** на сумму слоёв (в редакторе SAMPLE). Они умножаются на естественную громкость звука. Щелчок добавляет точку, перетаскивание двигает, двойной щелчок (или правая кнопка) удаляет, **Flat** сбрасывает.

## Редактор SAMPLE

Открывается щелчком по блоку SAMPLE, закрывается **Done**. Сверху общая шкала с финальной огибающей (белая линия, её можно рисовать) и кривой затухания после пика (в Release), под ней группы **MODE** (Swell / Arrive), **PEAK / AFTER PEAK** (Peak Move, режим и время **Fade** для Release) и **NOTE** (Attack, Release, Curve, Volume). Под шкалой краткая подсказка по жестам. В строке сверху написано, когда наступает пик и когда стартует каждый слой. Файл, брошенный на дорожку слоя, загружается в этот слой.

## Настройки слоя

| Группа | Ручка | Что делает |
|---|---|---|
| SOURCE | **Root** | нота, на которой сэмпл звучит в исходной высоте (по умолчанию C3 = MIDI 60). В поле можно ввести имя ноты, например `A#2` |
| | **Start / End** | участок файла, который играет слой. Их же можно тянуть мышью на волне (метки **S** и **E**) |
| TIME | **Mode** | **Stretch**: высота и длина независимы (time-stretch). **Resample**: как плёнка, выше нота = короче звук |
| | **Length** | только в Stretch: **Sample** (длина участка), **Seconds** (секунды) или **Beats** (доли по темпу DAW) |
| | **Seconds / Beats** | длина звука. Она одинакова на любой ноте |
| | **Peak offset** | сдвиг слоя относительно PEAK, ±8 с (то же, что Shift + перетаскивание на шкале). Часть, которая попала бы раньше начала ноты, обрезается и на волне затемнена (trimmed) |
| SOUND | **Pitch** | транспонирование слоя, ±24 полутона |
| | **Level, Pan, Width** | громкость (до −inf), панорама, ширина стерео (0 % = моно, 200 % = шире) |
| | **Low Cut / High Cut** | срез низа и верха (Off на 20 Гц и 20 кГц) |

Щелчок и удержание на волне: слой звучит один. Под волной: **VOLUME ENVELOPE** слоя (рисуется мышью, кнопка **Flat**, Cmd/Ctrl + щелчок сбрасывает точку); часть, отрезанная Peak Move, затемнена. Над ручками строка о длине и жёлтые предупреждения: сильное растяжение (в 3 раза и больше), предел растяжения, и нота дальше октавы от корня (`Last note E5 is +16 st from the root`).

Двойной щелчок по ручке возвращает значение по умолчанию. **Load...** загружает файл в слой, **Clear** очищает слой целиком: сэмпл, все ручки, ON/R и огибающую (кнопка неактивна, если слой и так в исходном состоянии), **Done** возвращает к обоим слоям.

## Отмена и повтор

- Отменяется всё, что меняется в окне плагина: ручки, переключатели, перетаскивание слоёв и флажка PEAK на шкале, метки S/E, огибающие, загрузка и очистка сэмплов, Clear.
- Одно действие = один шаг: перетаскивание ручки или точки огибающей целиком, прокрутка колесом, два файла, брошенных разом. Хранятся последние 8 шагов. Новое изменение после отмены стирает шаги для повтора.
- Автоматизация из DAW в историю не попадает. Открытие проекта или пресета очищает историю (она не сохраняется в проекте).
- Файл, который ещё загружается, считается последним действием: Cmd/Ctrl+Z отменяет загрузку (в строке состояния «Loading cancelled»), прежний сэмпл остаётся. Загрузка проекта в историю не попадает.
- Сочетания клавиш работают, когда окно плагина активно (щёлкните по нему). Некоторые DAW оставляют Cmd/Ctrl+Z себе: тогда пользуйтесь кнопками **Undo** и **Redo**.

## Как проверить

1. Создайте инструментальную (MIDI) дорожку и вставьте Reverse Sampler.
2. Перетащите два аудиофайла разной длины на окно плагина: они попадут в Layer 1 и Layer 2.
3. Сыграйте C3 и посмотрите на блок SAMPLE: короткий слой начинается позже, пики совпадают.
4. Откройте настройки слоя, нарисуйте огибающую под волной, покрутите **Peak offset**. Нажмите и держите волну: слой звучит один.
5. Щёлкните по SAMPLE: нарисуйте финальную огибающую, переключите **After peak** (Freeze и Loop слышны, пока держите клавишу).
6. На шкале: Shift + перетащите второй слой, чтобы его удар совпал с ударом первого (почувствуйте прилипание), потяните флажок PEAK влево до нужного транзиента, Option/Alt + удерживайте слой, чтобы послушать его отдельно, Cmd/Ctrl + колесо для увеличения.
7. **Arrive**: включите и сыграйте ноты по сетке в DAW, пик должен приходить на долю. Это нужно проверить именно в DAW: компенсация задержки (PDC) делается хостом. В Standalone компенсации нет, там пик просто приходит позже нажатия.

Полный список ручной проверки в разных DAW (сохранение проекта, экспорт, автоматизация, смена частоты и буфера, задержка) лежит в `TESTING.md`.

## Как это звучит

- **Root note без изменений** (Stretch, Length = Sample, Pitch 0, частота файла равна хосту): time-stretch не включается. Для прозрачного сравнения нужны ровные огибающие, единичные уровни и выключенные FX/фильтры. В новом экземпляре Attack = 0 мс вместо 5 мс; сохранённый Attack старых проектов не переопределяется.
- **Stretch** использует Signalsmith Stretch с `presetDefault` и более плотным перекрытием вместо `presetCheaper`. Растянутый или транспонированный звук может размываться, особенно при сильных изменениях. Текущий Windows-замер: 4 секунды, 8 нот × 2 слоя — 622 мс (mono 48 кГц) и 1022 мс (stereo 44,1 кГц). Это оффлайн-замер на данной машине, не гарантия real-time; подробности в `AUDIO_QUALITY.md`.
- В начале и в конце участка, если он вырезан из середины файла, делается плавный вход и выход 2 мс, чтобы не было щелчков.
- **Resample**, транспонирование и файлы с другой частотой дискретизации (например, 44,1 кГц в проекте на 48 кГц) читаются через windowed sinc (24 точки, окно Кайзера): ровно примерно до 0,4 частоты дискретизации файла, отражения и алиасы подавлены на 43 дБ и больше (выше 0,6 частоты дискретизации больше чем на 80 дБ). При транспонировании вверх фильтр сам сужает полосу, так что верх не заворачивается вниз (полностью до скорости ×4, то есть двух октав вверх для файла на частоте проекта). Файл на частоте проекта на корневой ноте играет бит в бит. Нагрузка небольшая: 8 нот × 2 слоя в Resample около 2,5 % одного ядра.
- Если нот больше 16, новая нота забирает самый старый голос: он затухает за 5 мс. Так же затухают ноты, которые останавливает загрузка, очистка, отмена/повтор смены сэмпла.

## Ограничения версии 0.6.0

- Режимы клавиш и зоны (2.9 концепции) не сделаны: им нужен Library Editor. «Живость» (2.10), Noise, макросы и библиотека пока не сделаны; базовые эффекты доступны в FX RACK.
- Arrive: задержка ограничена 1 с, чтобы не удерживать мониторинг/хост на длинных сэмплах; если нарастание длиннее, его начало обрезается, а PEAK всё равно попадает на ноту. Если меняется задержка, некоторые DAW применяют её только после перезапуска воспроизведения.
- R, Mode, Length, Pitch, Root, Start/End, Peak offset, Peak Move, Swell/Arrive, After peak и огибающие применяются со следующей ноты.
- Прослушивание слоя (Option/Alt + удержание, удержание волны) играет корневую ноту слоя (Root) с полной громкостью и не зависит от MIDI. В Arrive оно звучит сразу, без задержки.
- Транзиенты ищутся простым детектором громкости: на очень плотном или шумном материале меток может быть мало или много. Тогда двигайте без прилипания (Option/Alt). Level, Pan, Width, фильтры и ON/OFF действуют сразу.
- Когда новый сэмпл готов (или сэмпл удалён, или это отменено), звучащие ноты останавливаются с затуханием 5 мс.
- Движки Stretch для всех голосов готовятся заранее, чтобы не выделять память во время игры: около 47 МБ на экземпляр при 48 кГц.
- Freeze сделан облаком коротких грейнов: на чистых тонах (синус, свист) громкость удержания немного «дышит», на пэдах, ревербе и шумовых звуках это почти не слышно.
- До 120 секунд на файл, используются первые два канала. В проекте хранится путь к файлу, а не сам звук. Если файл переместили, слой показывает «Not found»: перетащите файл на слой снова.
- Проекты из 0.1–0.5.0 открываются (новые настройки получают значения по умолчанию: Swell, Cut, ровные огибающие, Peak Move 0, исходная кривая затухания). Dissolve из 0.3–0.4 открывается как Release с тем же временем и кривой, звучит иначе (без грейнов).
- Здесь проверено только на Linux: автотесты, VST3 validator (47 из 47), pluginval на максимальной строгости, Standalone. Windows и macOS проверяет GitHub Actions (сборка, тесты, pluginval, auval); в DAW нужно проверить вручную по `TESTING.md`.

## Полезное

- **Автотесты:** `cmake -B build -DRS_BUILD_TESTS=ON`, `cmake --build build --config Release --target ReverseSamplerTests`, затем запустите `build/ReverseSamplerTests_artefacts/Release/ReverseSamplerTests`. В конце должно быть «… passed, 0 failed».
- **GitHub Actions:** положите проект в репозиторий на GitHub, и при каждом push `.github/workflows/build.yml` соберёт и проверит плагин на трёх системах. Готовые плагины лежат в артефактах на вкладке Actions (на macOS они не подписаны, см. `TESTING.md`).
- **Проект для IDE:** на Windows откройте `build/ReverseSampler.sln` в Visual Studio (F5 запускает Standalone). На macOS: `cmake -B build-xcode -G Xcode`, затем откройте `.xcodeproj`.
- **Сборка без интернета:** скачайте JUCE 9.0.5 и укажите путь: `cmake -B build -DLOCAL_JUCE_PATH="C:/dev/JUCE"`.
- **Автокопирование после каждой сборки:** `cmake -B build -DRS_COPY_PLUGIN_AFTER_BUILD=ON` (на Windows нужен терминал от имени администратора).
- **Universal binary для macOS** (Apple Silicon и Intel): `cmake -B build -DCMAKE_OSX_ARCHITECTURES="arm64;x86_64"`.
- **Название и производитель** задаются в `CMakeLists.txt` (`PRODUCT_NAME`, `COMPANY_NAME`). `PLUGIN_CODE` и `PLUGIN_MANUFACTURER_CODE` лучше не менять, когда плагин уже используется в проектах: по ним DAW узнаёт плагин.
- **Logic не видит обновлённый AU:** выполните `killall -9 AudioComponentRegistrar` и перезапустите Logic.

### Reverb 0.14.0 — алгоритмы по референсам

| Режим | Decay | Что изменилось |
|---|---|---|
| Ambience | 0.2–1.0 с | 4 диффузора (g 0.72) вместо 3, затухание стен 4–8 кГц при Tone 50 %, мягкий подъём ER 3 мс — транзиент не размывается |
| Room | 0.3–3.0 с | НЧ-полоса затухания поднята до 350 Гц, бас ×1.3 — тёплые низкие середины |
| Plate | 0.5–6.0 с | Дисперсия: 16 allpass 1-го порядка перед пластиной, НЧ приходят на ~3 мс позже ВЧ; бас ×0.8 — без «коробки» |
| Terrain | 0.8–10 с | Поглощение воздуха 12 дБ/окт выше 2.5–5.5 кГц, тёмные отражения (≈4 кГц вблизи, 1.5–2 кГц у горизонта), 6 флаттер-эхо между скалами L/R |
| Bloom | 2–25 с | Attack = длина нарастания 50–500 мс |
| Shimmer | 2–25 с | ФНЧ в петле 3.5–8 кГц от Tone (≈5.3 кГц по умолчанию) |

Уровни пересчитаны: громкость wet по умолчанию в пределах ±0.2 дБ от dry во всех режимах.
